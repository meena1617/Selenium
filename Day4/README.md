# Day 04 - Running Selenium Code and Finding Elements

## Running the Code

Today I learned how to run Selenium programs using Eclipse and IntelliJ IDEA. I also understood how to check errors in the IDE. If there is any error, we need to check the line number and verify whether the required imports are added correctly.

## Working with a Login Page

I practised working with a login page using Selenium. First, I opened the application using driver.get(). Then I located the username and password fields and entered values using sendKeys(). After entering the details, I found the login button and clicked it using click().

## Why an Element is Not Found

I learned why Selenium sometimes cannot find an element on a webpage. If the element is not loaded or visible, Selenium cannot identify it and may throw an exception. This can happen when the webpage takes more time to load.

## Maximize the Browser

I learned how to maximize the browser window using driver.manage().window().maximize(). This helps us view the complete webpage while performing automation.

## What I Learned

Today I learned how to run Selenium code, interact with login page elements and understand why an element may not be found. I also practised maximizing the browser window.
