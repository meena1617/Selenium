# Day 03 - First Selenium Code

## Creating a Maven Project

Today I started writing my first Selenium automation program. I learned how to create a Maven project in Eclipse or IntelliJ. Inside the project, I created a package and a Java class to write the Selenium code.

## Dependencies

I learned that Selenium dependencies must be added inside the pom.xml file. Without adding the required dependencies, Selenium classes like WebDriver and ChromeDriver will not work.

The two dependencies used are Selenium Java and WebDriverManager. I learned how to search for these dependencies in Maven Repository, copy the dependency code and add it inside the dependencies section of pom.xml.

## WebDriver

WebDriver is an interface in Selenium used to control the browser. We write Java code, and WebDriver helps to open the browser and perform different actions.

## Chrome Browser

I learned that Chrome browser must be installed in the system when we use ChromeDriver in our program.

## Basic Code Flow

I created my first Selenium program using WebDriver and ChromeDriver. I used new ChromeDriver() to open the browser and driver.get() to open a website.

## What I Learned

Today I learned how to create a Maven project, add Selenium dependencies and write my first Selenium program. I also understood how WebDriver controls the browser and opens a website.
