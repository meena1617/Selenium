# Day 01 - Automation Testing Basics

## Manual Testing

Today I learned about manual testing. Manual testing means testing an application step by step without using any tools. We check whether the actual result matches the expected result.

## Manual vs Automation Testing

I learned the difference between manual testing and automation testing. Manual testing is performed by a person, whereas automation testing is done using scripts and tools. Manual testing takes more time, but automation testing is faster and useful when we need to repeat the same test cases.

## Test Case

A test case is a set of steps with input data and expected results used to check a particular feature. I also learned about high-level test cases and low-level test cases. High-level test cases contain general descriptions, while low-level test cases contain detailed steps.

## Test Scenario

A test scenario is a one-line description of what we need to test. For example, verifying the login functionality. One test scenario can have multiple test cases.

## How to Reduce Test Steps

I learned how to reduce unnecessary steps in test cases by keeping one objective in each test case, removing repeated steps, combining related steps and writing short and clear steps.

## Automation Testing

Automation testing means executing test cases automatically using tools and scripts instead of performing them manually. We will use Java for automation testing.

## Requirements for Automation

The basic requirements for starting automation testing are Java JDK and an IDE such as Eclipse or IntelliJ IDEA.

## Installation

Today I also learned how to install Java JDK and configure the JAVA_HOME environment variable. I learned how to check the Java installation using java -version and javac -version commands. I also installed Eclipse IDE and IntelliJ IDEA.

## What I Learned

Today I understood the basics of software testing, manual testing, automation testing, test cases and test scenarios. I also learned how to set up Java and the required IDEs for automation testing.
