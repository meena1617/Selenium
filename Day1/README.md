Topics Covered: Today I learned about software testing and the basics of automation testing. I understood the difference between manual testing and automation testing. 
Manual testing is performed by a person, whereas automation testing is performed using tools and scripts. I also learned about test scenarios, test cases, high-level test cases 
and low-level test cases.

Manual Testing: Manual testing means checking an application manually without using any automation tools. We perform different steps and verify whether the application is working correctly.

Automation Testing: Automation testing is used to execute test cases automatically using programming languages and tools like Selenium.
