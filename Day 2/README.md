# Day 02 - Maven Project Basics

## What is Maven?

Today I learned about Maven. Maven is a build and project management tool used for Java projects. It helps to create the project structure, manage dependencies and build the project.

## Why Maven?

I learned why Maven is used in Java projects. We don't need to download and add JAR files manually. We can simply add dependencies in the pom.xml file, and Maven downloads the required files automatically. It also provides a standard project structure.

## Project Structure

I learned about the basic Maven project structure. The src/main/java folder is used to store main Java files, and src/test/java is used to store test files. The pom.xml file contains project configuration and dependency details.

## pom.xml (Project Object Model)

pom.xml is an important XML file in a Maven project. It contains project information, dependencies and build configurations. I learned about groupId, artifactId, version, packaging, properties, dependencies, dependencyManagement, build, plugins, pluginManagement and repositories.

## Repositories

I learned that Maven downloads the required JAR files from repositories. Maven Central is a public repository. Companies can also use private repositories like Nexus to store and manage their project dependencies.

## Running a Maven Project

I created a Maven project and understood how to run a Java program inside it. Java code is written inside src/main/java. We can open the Java class and run it like a normal Java program. The main difference is the project structure.

## What I Learned

Today I understood Maven basics, its project structure and the importance of pom.xml. I also learned how Maven manages dependencies and downloads the required JAR files automatically.
